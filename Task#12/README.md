# React E-Commerce Website

This is a simple e-commerce website built with **React** and deployed on **Netlify**.  
It demonstrates a basic online store setup where users can browse products, add them to the cart, and proceed with a checkout flow (demo only).

🌐 **Live Demo**: [View Website](https://ecommerce-reacjst.netlify.app/)

---

## ✨ Features
- Modern UI built with React
- Product listing with images, names, and prices
- Shopping cart functionality
- Responsive design for mobile and desktop
- Easy deployment with Netlify
