# Contact Form React App

A simple and responsive React contact form project deployed with Netlify.

## Live Demo

View the live version here: [Contact Form Live](https://contactform-reactjs.netlify.app/)

## Features

- Responsive contact form built with React.
- Dummy form submission handler (alerts and logs form data).
- Custom styling using Tailwind CSS.
- Animated hover effects for interactive experience.
- Easy Netlify deployment for hosting with continuous updates.
