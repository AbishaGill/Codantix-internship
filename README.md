# Codantix Frontend Internship 🚀

This repository contains all my assigned tasks (Task 1 – Task 12) completed during the **Codantix Frontend Internship** program.  
Each task demonstrates the use of **React.js** and **TailwindCSS** to build modern, responsive, and functional frontend components and mini-projects.

---

## 📂 Project Structure
The repository is organized task-wise. Each task has its own dedicated folder/file containing the source code.
